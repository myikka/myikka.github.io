This website sets no cookies, has no analytics and loads nothing from other sites.

This policy covers this website, myikka.github.io, run by the developer of myikka. Questions about privacy: dev864392@gmail.com.

This website

  • The site is hosted by GitHub Pages. GitHub logs each visitor's IP address for security, as described in GitHub's privacy statement. We don't see or use these logs.
  • The site sets no cookies, has no analytics and loads nothing from other sites. Its only script is its own: it highlights the menu as you scroll, and reads, stores and sends nothing.

E-mail

If you write to us, we use your address and message only to reply. We delete them when you ask, unless the law requires us to keep them. Please never send card numbers, OTPs or passwords.

Children

This website is about myikka, which is meant for adults who hold credit cards. It isn't directed at children.
